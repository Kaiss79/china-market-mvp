# China Market MVP

Это стартовый каркас интернет-магазина / маркетплейса.

## Что внутри

- Next.js — сайт и серверная логика
- TypeScript — язык программирования
- Prisma — работа с базой данных
- SQLite — простая база для старта
- Каталог товаров
- Страница товара
- Корзина-заготовка
- Оформление заказа
- Админ-страница для просмотра товаров

## Как запустить

### 1. Установи Node.js

Скачай LTS-версию Node.js с официального сайта.

### 2. Открой папку проекта в VS Code

Открой терминал в VS Code и выполни:

```bash
npm install
```

### 3. Создай базу данных

```bash
npx prisma migrate dev --name init
```

### 4. Добавь тестовые товары

```bash
npm run seed
```

### 5. Запусти сайт

```bash
npm run dev
```

Потом открой в браузере:

```txt
http://localhost:3000
```

## Важные страницы

```txt
/                 каталог
/product/ID       карточка товара
/cart             корзина
/checkout         оформление заказа
/admin/products   админка товаров
```
